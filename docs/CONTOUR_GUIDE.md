# 📐 등고선 판독 및 지형 단면 분석 가이드 (Contour & Cross-Section Guide)

> **지형 탐험가 (Geography Explorer)**의 핵심 분석 도구인 **인터랙티브 2D 등고선도**, **실시간 A-B 지형 단면 프로파일**, 그리고 **3D 수직 슬라이스 평면**의 판독 원리와 지리 교육 활용법을 안내합니다.

---

## 🧭 1. 등고선(Contour Line)의 기초 원리

등고선은 지도 상에서 **해발 고도가 같은 지점들을 연결한 폐곡선**입니다. 2차원 평면 지도 위에 지표면의 3차원 입체 형태(고도, 경사, 계곡, 능선)를 정량적으로 표현하는 핵심 수단입니다.

### 1.1 등고선의 4가지 종류
1. **주곡선 (Index Contour)**:
   - 굵은 실선으로 표시되며, 고도 수치가 직접 기록되는 기준선입니다.
   - 통상 간곡선 5조마다 하나씩(예: 1:50,000 지형도 기준 100m 간격) 배치됩니다.
   - 앱 내에서는 시인성이 높은 주황/황금색 굵은 선(2.5px)으로 강조됩니다.
2. **간곡선 (Intermediate Contour)**:
   - 주곡선 사이를 5등분하는 얇은 실선(1px)입니다.
   - 지형의 세부적인 기복과 경사 변화를 나타냅니다.
3. **조곡선 (Supplementary Contour)**:
   - 경사가 매우 완만하여 간곡선만으로는 지형의 굴곡을 표현하기 어려운 평야나 갯벌, 사구 등에서 간곡선 사이에 파선(점선)으로 표기합니다.
4. **계곡선 (Valley Contour) & 능선선 (Ridge Contour)**:
   - 등고선의 굴곡 형태에 따라 지형의 수계 및 분수계(능선)를 식별합니다.

## 🔍 2. 등고선으로 지형 읽는 법 (Reading Topography)

### 2.1 경사도 (Slope Gradient) 판독법
- **등고선 간격이 좁을 때**: 수평 거리 대비 고도차가 급격히 변함을 의미 $\to$ **급경사 (Steep Slope)** 또는 **절벽 (Cliff)**
- **등고선 간격이 넓을 때**: 수평 거리에 따른 고도 변화가 완만함을 의미 $\to$ **완경사 (Gentle Slope)** 또는 **평야 (Plain)**
- **등고선이 겹칠 때**: 지표면이 수직으로 서 있는 **해식애(파식 절벽)**, **단층애**, **폭포 직벽**

### 2.2 능선(Ridge) vs 계곡(Valley) 구별 공식
| 구분 | 등고선 굴곡 방향 | 고도 변화 특성 | 실제 지형 |
| :--- | :--- | :--- | :--- |
| **능선 (Ridge)** | **낮은 곳을 향해** 볼록하게 튀어나옴 | 중앙축의 고도가 양옆 사면보다 높음 | 빗물이 양 갈래로 분산되는 분수계 |
| **계곡 (Valley)** | **높은 곳을 향해** V자 또는 U자로 쑥 들어감 | 중앙축의 고도가 양옆 사면보다 낮음 | 빗물이 모여 하천이 흐르는 집수 지형 |

### 2.3 봉우리(Peak)와 분지/와지(Depression)
- **산봉우리 (Summit/Peak)**: 폐곡선의 가장 중심부로 갈수록 고도가 증가하는 동심원 형태.
- **분지 및 와지 (Caldera, Sinkhole)**: 폐곡선 중심부로 갈수록 고도가 낮아지는 구조. (등고선 안쪽에 빗금 안쪽 표시 또는 물웅덩이 표기)

## ✂️ 3. A-B 지형 단면도 (Cross-Section Profile) 생성 원리

### 3.1 인터랙티브 절단선 설정
사용자는 2D 등고선도 화면 어디서나 마우스를 드래그하여 임의의 시작점 $A(x_1, y_1)$과 끝점 $B(x_2, y_2)$을 지정할 수 있습니다.

### 3.2 수치 보간 파이프라인
1. **균등 샘플링**: 선분 $AB$를 $N=100$개의 등간격 지점 $P(t) = A + t(B - A)$ ($t \in [0, 1]$)로 분할.
2. **바이리니어 보간 (Bilinear Interpolation)**: DEM 표고 그리드의 4개 인접 셀 값 $Z_{00}, Z_{10}, Z_{01}, Z_{11}$로부터 $P(t)$의 정밀 표고값 $Z(t)$를 연속 계산:
   $$Z(u, v) = (1-u)(1-v)Z_{00} + u(1-v)Z_{10} + (1-u)vZ_{01} + uvZ_{11}$$
3. **고도 프로파일 차트 렌더링 (`ElevationProfileChart.tsx`)**:
   - 가로축: $A$점으로부터의 수평 누적 거리(km / m)
   - 세로축: 해발 고도(m)
   - 실시간 최대 고도, 최저 고도, 평균 경사각($\theta = \arctan(\Delta Z / \Delta X)$) 산출.
4. **마우스 호버 추적 (Interactive Hover Linking)**:
   - 단면 프로파일 차트 위로 마우스를 움직이면, 2D 등고선도 상의 해당 좌표에 **십자선 인디케이터**와 **실시간 고도 툴팁**이 연동 표시됩니다.

## 🧊 4. 3D 수직 슬라이스 평면 (Elevation Slice Plane)

2차원 단면도를 3차원 공간으로 확장한 고급 시각화 도구입니다.

- **원리**: 3D 지형 디오라마 메쉬 내부에 단면선 $AB$를 관통하는 반투명 수직 평면(`ElevationSlicePlane.tsx`)을 생성.
- **지질 층상 단면 표현**: 3D 슬라이스 평면의 절단면에 지형의 고도 변화가 붉은색 외곽선(Cut Edge)과 수직 음영으로 즉시 투영되어, 학생이 2차원 등고선 단면도와 3차원 입체 지형의 상관관계를 한눈에 체득할 수 있습니다.

### 💡 추천 실습 시나리오
1. **[초등/중등] 등고선으로 보물찾기**:
   - 칼데라(백두산 천지)와 화산(한라산)의 2D 등고선도를 열고, 중심부가 높은지 낮은지 확인하여 분화구와 칼데라의 차이점을 도출.
2. **[고등 한국지리] 하천 침식 지형과 단면 비교**:
   - 영월 감입곡류천을 선택하고, 곡류천 외측(공격사면, 급경사 절벽)과 내측(포인트바 퇴적사면, 완경사)을 가로지르는 단면선 $A-B$를 그어 비대칭 단면 곡선을 실측 비교.
3. **[고등 지구과학] 빙하 U자곡과 하천 V자곡 판독**:
   - 스위스 U자곡과 영월 V자곡의 단면도를 각각 생성하여 밑바닥의 평탄도와 계곡 양 벽의 수직 절벽 경사각을 정량 비교.
